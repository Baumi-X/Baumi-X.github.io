Kurzfassung

Welche Daten werden gespeichert?

Evo Command speichert folgende Daten lokal auf deinem Gerät (im privaten App-Speicher der App):

  • Laufender Spielstand (aktuelle Partie, damit du sie fortsetzen kannst)
  • Einstellungen (Sprache, Grafikqualität, Ton an/aus, Lautstärke, Anzeige der Leistungswerte)
  • Statistik beendeter Partien (gestartete Partien, Siege, Niederlagen, Abschüsse, Spielzeit, kürzester Sieg)
  • Von dir erstellte Vorlagen (benannte Bauweisen deiner Kreaturen)
  • Fortschritt im Spiel (z. B. freigeschaltete Bauplan-Plätze, Tutorial-Fortschritt)

Diese Daten enthalten keine personenbezogenen Informationen (keinen Namen, keine E-Mail-Adresse, keine Kontaktdaten, keinen Standort, kein Foto-/Video-/ Mikrofon-Zugriff). Namen von Vorlagen sind freie Texte, die du selbst eingibst; sie bleiben auf deinem Gerät und werden nicht übertragen.

Werden Daten an Server übertragen?

Nein. Evo Command ist ein vollständig offline lauffähiges Spiel. Es findet keine Übertragung von Spieldaten an uns oder Dritte statt. Es gibt keine Server-Anfragen für Gameplay, Spielstände oder Nutzerprofile.

Analytics, Werbung, Tracking

Evo Command verwendet keine Analytics-Dienste (z. B. Google Analytics, Firebase Analytics), keine Werbenetzwerke, keine In-App-Käufe und keine Tracking-/Fingerprint-Mechanismen. Es findet kein Abgleich mit Werbe-IDs statt.

  • Firebase (in der App): keine

Geplant ist ein Mehrspieler-Modus im lokalen Netzwerk (z. B. im selben WLAN): Ein Spieler hostet die Partie, die anderen treten bei. Dabei werden Spieldaten direkt zwischen den beteiligten Geräten im lokalen Netzwerk ausgetauscht. Es gibt keinen Online-Server und keine Verbindung zum Entwickler. Diese Funktion ist noch nicht enthalten. Sobald sie veröffentlicht wird, wird diese Datenschutzerklärung (inklusive der Liste der Dienste und Berechtigungen) vorher aktualisiert. Berechtigungen

Evo Command benötigt keine besonderen Geräteberechtigungen (kein Zugriff auf Kamera, Mikrofon, Kontakte, Standort, Dateisystem außerhalb des eigenen App-Speichers).

Datenlöschung

Da alle Daten ausschließlich lokal gespeichert werden, kannst du sie jederzeit selbst löschen, indem du die App-Daten von Evo Command über die Android-Systemeinstellungen löschst oder die App deinstallierst. Es gibt keine serverseitig gespeicherten Daten, die separat gelöscht werden müssten.

Kinder

Evo Command richtet sich nicht gezielt an Kinder, fragt kein Alter ab und sammelt generell keine Daten. Da Evo Command keine personenbezogenen Daten erhebt, keine Kommunikation mit anderen Nutzern ermöglicht und keine Werbe-/Tracking-Mechanismen enthält, bestehen aus datenschutzrechtlicher Sicht keine besonderen Risiken für jüngere Spieler.

Änderungen dieser Datenschutzerklärung

What data is stored?

Evo Command stores the following data locally on your device (in the app's private storage):

  • Current game save (the match in progress, so you can continue it)
  • Settings (language, graphics quality, sound on/off, volume, performance display)
  • Statistics of finished matches (matches started, wins, losses, kills, play time, fastest win)
  • Templates you create (named builds of your creatures)
  • Progress in the game (e.g. unlocked blueprint slots, tutorial progress)

This data contains no personally identifiable information (no name, email address, contact details, location, or camera/microphone/photo access). Template names are free text that you enter yourself; they stay on your device and are not transmitted.

Is data transmitted to any server?

No. Evo Command is a fully offline-capable game. No gameplay data is transmitted to us or any third party. There are no server requests for gameplay, save data, or user profiles.

Analytics, advertising, tracking

Evo Command does not use any analytics services (e.g. Google Analytics, Firebase Analytics), advertising networks, in-app purchases, or tracking/fingerprinting mechanisms. No advertising ID matching takes place.

Currently used services

As of this privacy policy, Evo Command uses the following services or features:

  • Analytics: none
  • Firebase (in the app): none
  • Advertising / AdMob: none
  • In-app purchases: none
  • Online features: none
  • Cloud storage: none

Note on test versions: before release, test versions are distributed to invited testers through Firebase App Distribution. This is a developer-side distribution channel only and not part of the game; the app itself contains no Firebase code.

A multiplayer mode on the local network (e.g. the same Wi-Fi) is planned: one player hosts the match and the others join. Game data is then exchanged directly between the participating devices on the local network. There is no online server and no connection to the developer. This feature is not included yet. Before it is released, this privacy policy (including the list of services and permissions) will be updated. The same applies to other future changes, e.g. a daily challenge.

Installation via Google Play

If you install Evo Command through Google Play, Google processes data as part of the Play Store (e.g. installation, updates and, if you have allowed it on your device, crash reports). Google's privacy policy applies to that. The developer only sees aggregated statistics in the Play Console.

Permissions

Evo Command does not require any special device permissions (no access to camera, microphone, contacts, location, or file system outside its own app storage).

Data deletion

Since all data is stored locally only, you can delete it at any time yourself by clearing Evo Command's app data via Android system settings or by uninstalling the app. There is no server-side stored data that would need to be deleted separately.

Children

Evo Command is not specifically directed at children, does not ask for age, and does not collect any data in general. Since Evo Command does not collect personal data, does not enable communication with other users, and contains no tracking/advertising mechanisms, there are no particular privacy risks for younger players from a data-protection standpoint.

Changes to this privacy policy

If Evo Command's actual feature set changes in the future (e.g. by introducing online features, analytics, or advertising), this privacy policy will be updated accordingly before such a version is released.
